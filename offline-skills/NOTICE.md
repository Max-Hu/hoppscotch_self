# 来源与许可

此目录整理并离线适配了多个上游的技能，不将上游作品声称为原创，也不统一替换其许可证。

- 每个技能的来源、固定提交和相对路径见 `skill-library/sources.lock.json` 与 `skills.lock.json`。
- 对上游的修改记录见 `skill-library/patches/`，离线适配和剔除的功能见审查报告。
- 各技能目录中保留相应 `LICENSE` / `LICENSE.txt` 等文件；引用的界面规范另附许可证。
- 纯 Python PyYAML 的许可见 `skill-library/tools/vendor/PYYAML-LICENSE`；上游格式验证器的许可见同目录 `OPENAI-SKILLS-LICENSE`。
- 技能引用某技术或工具不表示需要使用该工具的云服务。原始归档和大型依赖保留在本地离线制品，不在此次 Git 源码分发范围内。
