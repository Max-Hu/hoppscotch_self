## 3. 剔除与保留边界

首批核心技能保留；Playwright CLI 备选项已整项剔除。其余移除了远程指令、图片及自动获取路径。通用依赖内部网络实现采用入口限制和配置禁用，并未声称全部物理删除。缺少制品时报告，不联网补齐。

远程 GitHub CI 修复、Linear / Notion 等服务工作流没有运行副本，因为获取远端状态是其主要用途；原始仓库归档可供审查。无法在保留同一远程功能的同时改成完全离线。本地需求管理、审查、测试不受影响，但不能通过这些入口同步远端任务、CI 或 PR。

Spec Kit 作为与 OpenSpec 重叠的替代工具包，完整源码已在本地，未安装其 CLI，也未生成运行技能。它并非不能离线使用；本次没有把其远程目录、扩展 hooks、GitHub 集成带入运行包。影响是不能直接调用 specify；推荐的 OpenSpec 主流程已具备本地运行入口。若后续改选它，需独立准备依赖、审核生成指令，不能把原始模板直接当成已审核技能。

## 4. 实际验证

格式、Python 语法和网络入口扫描由 `tools/audit_library.py` 执行。逐项证据见 `audit/network-review.json`；技能文件哈希见 `audit/skill-files.sha256.json`。

行为测试由 `tests/test_offline_library.py` 执行，机器可读结果见 `tests/results.json`。检查包括：

1. 非回环 DNS/TCP 在 Python 测试进程中被阻断。
2. 回环 HTTP 可以访问。
3. 浏览器 URL 的回环判定，包括伪装主机名与远程 file share。
4. 真实 headless Edge 的本地表单、状态局部更新、非本机 HTTP 拦截及 WebSocket 不转发。
5. 本地 Hypothesis 能实际生成反例，非仅检查 import。
6. 本地 Python 测试服务的启动、就绪与退出清理。
7. 服务 helper 拒绝在线包启动命令。
8. OpenSpec 包装器拒绝更新、安装、store、URL 参数及重新生成宿主技能。
9. OpenSpec 在隔离目录初始化、建立 change、读取状态与模板、归档；没有初始化真实项目。

新增检查：组合解释器选项拒绝、服务 helper 组合参数拒绝、旧扫描盲区回归、全部浏览器示例 context guard、Node 可视化服务的本地品牌/CSP/非回环绑定拒绝；OpenSpec 原检查还增加了重复 tools 和 cloud 参数变体。

本次结果：40 个技能入口格式校验通过，224 个技能资源及适配器文件已记录哈希，所定义的网络入口扫描无未处理项，14 项行为冒烟及复审回归检查全部通过，无跳过。扫描范围和规则有限，不以零扫描告警代替零外联保证。

上述是技能和适配工具的冒烟验证，不是平台业务的生产验证。没有做系统级抓包、Linux 实机执行、所有宿主 hooks 测试或让每个 skill 处理真实业务的模型行为评估；不能据此宣称所有程序/进程永不联网。

## 5. 使用前提

Windows x64 CPython 3.12 + 本机 Edge 已用于实际测试；Linux x64 的工具依赖和 OpenSpec 已准备但未运行。Python 解释器、浏览器本体和 Linux 系统库不在包内。其他版本/架构必须另外准备，不可临时联网。

包内 Python socket guard 不约束原生 OpenSpec 二进制或任意子进程；原生 CLI 以源代码审查、关闭外联配置和命令 allowlist 限定范围。封闭网络的最终隔离仍由实际环境提供。浏览器 guard 控制页面请求与被拦截 socket，不是整机或浏览器后台进程的防火墙。
