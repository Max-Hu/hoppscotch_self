# 集中的项目规则

本文件是离线技能库的通用规则入口。采用到具体项目时，在这里补充该项目已经确定的技术选择、业务契约和验证要求；不要把同一业务规则复制进每个 skill。

- 正式使用只读本地代码、文档、日志、Git 历史及预置工具。不获取在线资料、不使用远程 MCP、不自动更新或安装依赖。URL 只标明来源，不表示应访问。
- 网络测试只使用任务明确指定的回环服务；第三方接口用本地 mock。Python 和浏览器使用本库受控入口，缺少依赖时报告缺口。
- 工具包装器不是 OS 网络沙箱，不控制所有原生子进程或宿主模型服务。严格隔离由实际运行环境提供。
- 单人工作可在当前会话完成。无可用独立审查者时标明自审，不虚构独立审查，不为使用技能接入外部代理服务。
- 在现有代码上修改时，先查看实现、调用方、未提交工作及已有测试。重构默认保留外部行为和持久化契约；必要行为变化明确说明。
- 需求与任务使用一个主入口，避免重复计划。小改动不强制完整流程；验证与风险相称，只报告实际执行的结果。
- 页面脚本、字体、图片和样式使用本地资源；不要加入 CDN 或在线 demo。
- 保留上游许可证、来源锁定、修改记录和审查边界。技能或适配器改变后重新审核相应内容哈希。
- 用户明确请求上传、更新或发布时只执行其授权范围；普通开发不自动 commit、push、merge、部署或修改共享数据。

具体项目待补充：技术栈、模块边界、重要接口及数据契约、业务不变量、迁移兼容策略、测试与验收命令。不要在此填写密码、token 或真实连接凭据。
